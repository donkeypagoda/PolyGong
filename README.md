# PolyGong (2017)

Archived. This is the original PolyGong, a musical mobile in the browser, built on Angular 1.6, Three.js, and Tone.js. It no longer runs or deploys.

It is being rebuilt as **PolyGong Mk2** (`../polyGongMk2`) on a modern stack with Rust/WASM audio. This repo stays as a read-only reference.

- What this code actually does, bugs included: [docs/legacy-app.md](docs/legacy-app.md)
